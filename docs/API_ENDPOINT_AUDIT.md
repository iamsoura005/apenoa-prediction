## 2. Request & Response Validation Results

### `POST /api/predict`
- **Valid 30s Input:** Successfully processed 2,400 floats. Returned JSON with `analysis_id`, `prediction`, `probability`, `biomarkers` (HR, SDNN, RMSSD, LF/HF), and 600-point preview array.
- **Malformed Input (Too Short):** Submitting a 2-sample array correctly triggered `400 Bad Request` with message: `"Signal too short. Minimum 1 second (80 samples) required."`
- **Zero Values:** Correctly handled without numerical division-by-zero errors.

### `POST /api/upload`
- **CSV Ingestion:** Upload of `sample_pre_apnea_onset.csv` parsed 2,400 rows into float array, ran forward pass, and returned `APNEA_EVENT (prob: 0.5011)`.
- **JSON Ingestion:** Upload of structured JSON containing metadata and array returned `NORMAL_BREATHING (prob: 0.486)`.

### `GET /api/report/{id}`
- **PDF Construction:** Invokes ReportLab document template. Verified generated byte stream contains valid PDF header (`%PDF-1.4`) with length ~4,180 bytes.
- **Cache Eviction:** Preserves up to 50 active analyses with FIFO eviction.
